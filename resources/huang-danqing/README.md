# 黄丹青 B 站视频资料

来源：[B 站用户页](https://space.bilibili.com/1667150867)，UID `1667150867`。

从原始 7,690 条投稿中，按去宣传文案后的主题、文字相似度和时长筛选重复副本，保留 5,606 条，合并 2,084 条。一般保留最新投稿；用户截图确认的四条合为一条，保留较长复盘版。

日期采用北京时间，数据获取日期：2026-11-01。保留原始完整标题，按发布时间从新到旧排列。

此次不再仅凭完整标题匹配：宣传语和标签的变化不再产生新的副本。不同集数、不同复盘标记或时长明显不同的视频谨慎保留，可能仍有标题相同的不同讲解。
